## Порядок изменения
1. Зафиксировать SHA/версию схемы, сделать экспорт с обезличенными тестовыми данными.
2. Запустить модельные и storage-тесты, затем UI и платформенные smoke.
3. Проверить миграцию и восстановление после сбоя, не перезаписывать пользовательский план шаблонами.
4. По окончании — QA с фактическими кодами завершения и HANDOFF для следующего агента.
