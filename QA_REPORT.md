Системный календарь `.ics` требует импорта пользователем; это несинхронизируемая копия расписания. У Mac-помощника используется ручное обновление экспортированного JSON.

## Аудит устойчивости — 22 октября 2026

- Исправлено разрушительное перезаписывание повреждённого localStorage при старте. При сбое сохранение блокируется, а повреждённая запись доступна для выгрузки.
- Добавлены пять регрессионных тестов `tests/storage.test.cjs`; всего 24 модульных теста в опубликованной версии.
- Увеличены сенсорные области нажатия кнопок, версия офлайн-кеша обновлена.
- Проверены интерфейсы 320, 390 и 1280 CSS-пикселей в Chromium; сенсорные элементы настроек 44x44 CSS-пикселей на 320/390, переполнения нет.
- Успешный GitHub Actions для коммита b877b45.
- Не проверены на реальных устройствах: Safari/macOS/iPhone, фоновая доставка при закрытом браузере, офлайн-поведение установленного PWA, размещение на GitHub Pages.
