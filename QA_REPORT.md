# Матрица проверки — универсальный планировщик

Дата: 22 октября 2026 года. Проверка исходников без реального устройства Apple.

| Направление | Проверка | Результат |
|---|---|---|
| Совместимость | Старый ключ localStorage `life.local.v2.local-life-planner` сохранён; нормализация прежних полей | Пройдено (unit + инспекция) |
| Редактирование | Разделы, названия, порядок, видимость, создание/редактирование/поиск пунктов | Пройдено (UI) |
| Календарь | Повторяющиеся и разовые дела, даты и переходы между днями | Пройдено (unit + UI) |
| Напоминания | Индивидуальный переключатель, тихие часы, откладывание, догон за 60 минут, смена даты после полуночи | Пройдено (unit); реальные системные уведомления не проверены |
| Покупки | Количество, чекбоксы, категории, время напоминания | Пройдено (UI + unit) |
| Финансы | Положительные суммы, баланс, CSV-экспорт с экранированием опасных формул | Пройдено (unit + UI) |
| Экспорт календаря | ICS: разовые и повторяющиеся дела, однократные события незавершённых покупок, перенос длинных UTF-8 строк | Пройдено (unit) |
| Архивы | Нормализация JSON, распознавание прежнего HTML без исполнения скриптов | Пройдено (unit) |
| Адаптивность | Chromium: 320 px, 390 px, 1280 px, без горизонтального переполнения | Пройдено (3 UI-сценария) |
| JS | Синтаксический контроль `node --check` и отсутствие pageerror в Chromium | Пройдено |
| PWA | Наличие файлов манифеста, service worker; инвалидация кеша `v3` | Инспекция кода. Автономный запуск по HTTP не проверен: браузерное окружение блокирует localhost |
| Safari/iPhone | Живые уведомления, разрешения ОС, установка и автономная работа | Не проверены на реальном устройстве |
| Доступность | Подписи полей, доступные названия кнопок и статусная область | Инспекция кода; формальный WCAG-аудит не выполнялся |
| Безопасность | Импорт ограничен размером; записи вставляются через textContent; CSV-формулы обезврежены | Инспекция кода и unit-тесты |
| Данные | Нет отправки пользовательских записей в облако; резервирование вручную | Инспекция кода; без сквозной сетевой трассировки |

**Автоматизированные результаты:** 19/19 модельных тестов; 3/3 UI-сценария. 

**Ограничения:** браузерный JS не вправе насильно выводить вкладку на передний план и не исполняет надёжные сигналы при полностью закрытом приложении. Системный календарь `.ics` требует импорта пользователем; это несинхронизируемая копия расписания. У Mac-помощника используется ручное обновление экспортированного JSON.
